======================================================================
     CHOCOLATE TRILOGY: Chocolate-Heretic + Chocolate-Hexen + Chocolate-Strife
======================================================================

Chocolate Trilogy is derived from my other project, Crispy Trilogy, and 
shares the same characteristics; the only exception is that it is not compatible 
with the new Heretic episode "Faith Renewed" due to the vanilla limitations 
of Chocolate-based source ports.

INTRODUCTION:

Chocolate Trilogy is a launcher created using C# Windows Forms, designed 
to unify the source ports Chocolate Heretic, Chocolate Hexen, and Chocolate 
Strife. We could say it is something like a home-grown and modest 
version of the official Heretic + Hexen release, but structured as 
a trilogy and built for a source port. Each session has its own parameters, 
multiplayer settings, WAD browser among other things.

For full screen mode you can press F1 and to return the screen to 
normal press Escape.


HOW TO USE AND INSTALLATION:

It is a simple launcher to use. Inside the zip file, you will find 
the main directory Chocolate-Trilogy which contains the launcher along 
with three subfolders: chocolate-heretic, chocolate-hexen, and chocolate-strife. 
All you have to do is place the corresponding source port files 
including all their required DLLs and configuration assets along with 
the game WADs inside these subfolders. The main Chocolate-Trilogy.exe 
file must sit right next to these folders to detect the games properly. 
There is no need to move anything else.
